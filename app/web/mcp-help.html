什么是 MCP？

MCP 可以理解为“智能体与应用之间的通用插座”。平时聊天时，智能体只能给你建议；连接 DDL Killer 后，它可以在你授权的范围内读取计划、创建任务，并先生成排期草案让你确认。

读懂你的安排查看清单、DDL、课程和已有日程。
帮你记录任务把对话里的事项直接加入 DDL Killer。
生成排期草案先预览多个安排，再一次性应用。
主动避免冲突课程冲突会阻止应用，普通重叠会明确提醒。

三步完成连接

在 DDL Killer 打开“我的 → 智能体连接”这里可以创建、查看和撤销所有连接。
优先选择 OAuth客户端会打开浏览器让你登录并确认权限，不需要复制令牌。客户端不支持 OAuth 时，再创建手动令牌。
把 MCP 地址交给客户端地址是 https://ddlkiller.com/mcp。连接成功后，可以先让智能体“列出我的清单”测试。
推荐：先选“任务与规划（推荐）”。它足够完成日常读取、创建任务和排期，又不包含永久删除权限。

常见客户端示例

Claude Code

添加远程 HTTP MCP，然后在浏览器中授权。

claude mcp add --transport http --scope user ddl-killer https://ddlkiller.com/mcp
claude mcp login ddl-killer

Codex

添加服务器后执行登录，Codex 会启动 OAuth 流程。

codex mcp add ddl-killer --url https://ddlkiller.com/mcp
codex mcp login ddl-killer

OpenClaw

当前建议在 DDL Killer 创建手动令牌，再写入连接配置。

openclaw mcp set ddl-killer '{"url":"https://ddlkiller.com/mcp","transport":"streamable-http","headers":{"Authorization":"Bearer <你的令牌>"}}'
命令因客户端版本不同可能略有变化。如果客户端已经提供“添加 MCP”界面，只需选择远程 HTTP / Streamable HTTP，填入上面的 MCP 地址，然后选择 OAuth 或 Bearer Token。

排期为什么分“草案”和“应用”？

智能体可以先生成整套方案供你检查；只有继续要求应用，日程才会真正改变。过期草案会被拒绝，课程冲突也不会被强行写入。

令牌与撤销

手动令牌只显示一次。创建后立刻保存到客户端的安全配置中，不要发到聊天、截图或公开文件里。服务器不会保存可还原的令牌原文。

不再使用某个客户端时，回到“智能体连接”，找到对应连接并点右侧的断开图标。撤销立即生效，客户端的下一次请求会被拒绝。若怀疑令牌泄漏，直接撤销并重新创建即可。

常见问题

连接成功后可以直接让 AI 自动改日程吗？

可以，但推荐让它先生成草案并解释安排，再由你确认应用。这样更容易发现时间偏好或优先级理解错误。

为什么显示未授权或 401？

OAuth 可能尚未完成，或手动令牌已过期、被撤销。重新登录，或在 DDL Killer 中创建一个新连接。

换手机或浏览器需要重新连接吗？

通常不需要。连接属于你的账号和智能体客户端，不依赖当前打开 DDL Killer 的设备。

AI 会看到我的密码吗？

不会。OAuth 只把授权结果交给客户端；创建手动令牌时，账号密码也只用于确认是你本人。
