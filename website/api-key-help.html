给 AI 助手接上自己的 Key

不需要写代码。以 DeepSeek 为例，获取一串密钥，填到 DDL Killer，再测试连接就可以了。

API Key 可以理解为让软件调用你所选 AI 服务的“专用钥匙”，不是 DDL Killer 的登录密码，也不是 DeepSeek 的账号密码。

DDL Killer 不收取任何软件使用费用。官方 AI 额度供新用户体验；长期使用推荐自己的 API Key，或 通过 MCP 接入自己的智能体。使用自己的 Key 时，AI 调用由对应服务商计费，费用由你承担。

第 1 步

到 DeepSeek 官方平台获取 Key

  1. 打开 DeepSeek 官方 API Key 页面，按平台提示注册或登录。
  2. 进入“API keys”页面，创建一个新的 API Key。名称可以填 DDL Killer，方便以后辨认。
  3. 复制生成的完整 Key。若平台只在创建时展示一次，请当场妥善保存；以后找不到时，可以撤销旧 Key，再创建新的。

请认准 platform.deepseek.com。只需在官方平台操作，无需把账号密码或验证码交给别人。

第 2 步

确认 API 余额与费用

在 DeepSeek 平台查看可用余额和用量。网页版聊天和 API 调用是不同入口；能在网页聊天，不代表 API 一定有可用余额。

API 按实际输入和输出的文字量计费，测试连接也会产生少量调用。不需要先购买大额套餐；如果余额不足，可按官方平台的规则小额充值，再根据实际使用决定是否继续。

查看 DeepSeek 当前价格与计费规则。价格可能调整，请以官方页面为准。

第 3 步

回到 DDL Killer，填写这四项

打开“我的 → AI 计划助手设置”，将“模型来源”切换为 使用自己的 Key。

提供商DeepSeek
API 地址https://api.deepseek.com/v1
选 DeepSeek 后自动填写，无需修改。
模型名称deepseek-flash
API Key粘贴刚才复制的完整 Key，不要填账号密码。

我们默认推荐 Flash，适合先用于日常任务安排，费用也比 deepseek-v4-pro 低。无需为了使用助手改成 Pro。

截至 2026 年 10 月 9 日，官方模型名称为 deepseek-flash 和 deepseek-v4-pro。如果旧配置仍显示 deepseek-chat，请手动改为 deepseek-flash，重新填写 Key 并保存。已有配置不会自动改写；后续模型名称变化时，我们会更新默认值和教程。

核对 DeepSeek 官方接入说明

第 4 步

先保存，再测试连接

  1. 点击 保存配置。如果提示验证账号密码，请填写你的 DDL Killer 密码后重试。
  2. 点击 测试连接。显示“连接测试成功”后，就可以打开 🎀 助手，试着描述一件想安排的事。
  3. 查看 AI 给出的方案，调整到满意后再确认。确认前不会写入任务或日程。

“测试连接”使用已保存的配置。刚修改了 Key 或模型名称时，要先保存，否则测试的仍是上一次配置。

遇到问题时

测试连接失败，先检查什么？

确认已保存最新配置；检查 Key 是否完整、是否已被撤销，模型名称是否为 deepseek-flash，以及官方平台的 API 余额。检查网络后再试一次。仍失败时，联系开发者并提供错误提示，不要发送完整 Key。

Key 会保存在哪里？可以删除吗？

配置保存到 DDL Killer 服务器，Key 加密存储，应用只显示掩码。使用助手时，服务器会用它向你选择的模型服务发送请求；相关任务、课程和安排也会用于生成方案。只使用你信任的服务。

在此页点击“删除配置”会删除 DDL Killer 保存的配置。若怀疑 Key 泄漏，还需要到 DeepSeek 官方平台撤销它，删除应用配置不会撤销服务商的 Key。

可以使用其他模型服务吗？

可以选择“自定义 OpenAI 兼容服务”，按服务商文档填写 HTTPS API 地址、模型名与 Key。保存前请核对接收 Key 的域名。不同服务的兼容性可能不同，先测试连接；不是把网页版聊天网址填进来就能使用。

暂时不想配置 Key 可以吗？

可以继续用官方体验额度，具体剩余次数以应用内为准；也可以通过 MCP 接入自己的智能体。清单、DDL、课表和基础日程功能不要求你购买 AI 服务。

教程核对日期：2026 年 10 月 9 日。平台界面和模型名称可能变化，请以官方页面为准。
