把课表和想做的事，安排在一起

从记录一件事开始，再为它留出时间。这份指南带你认识任务、课程与日历，也说明数据怎样保存和同步。

使用网页版 下载 Android

第一次使用

  1. 打开网页版或 Android 应用，注册或登录账号。注册需要邮箱验证码；已有账号可在「我的 → 邮箱」绑定常用邮箱，以便找回密码。
  2. 自己的设备可保留登录页的「在此设备启用离线数据」。公共设备建议取消勾选，并在离开前完成同步、退出账号。
  3. 进入最左侧页面，点左上角菜单，选择「收集箱」或自己的清单，再点 ＋ 记录一个任务。需要上课时，可先到「我的 → 导入课表」。

网页版与 Android 使用同一账号，可同步已上传的数据。iPhone、iPad 目前请通过浏览器使用。

几个页面怎么分工

底部从左到右是清单、日历、DDL 和「我的」。最左侧默认打开「今天」，左上角菜单可以切换清单。

今天
按时间查看当天课程、任务排期和独立日程；今天截止但还未排时间的任务会另列在下方。
清单
把事情按课程、项目或用途分类。「收集箱」暂存想法；未归入清单的任务可在「其他」找到。
日历
查看实际要做事的时间，以及已导入的课程。可切换日、三日、周或月视图。
DDL
关注已过期和未来 30 天内的截止日期。点选日期，看那天到期的任务；没有 DDL 不代表当天没有课程或安排。
我的
管理邮箱、课表、AI、提醒、同步、外观与账号数据，也能查看消息和提交反馈。

任务与执行时间

截止日期是“最晚何时完成”，日历安排是“准备何时做”。例如，周五交的作业，可以安排在周三晚上完成；调整执行时间不会自动改变截止日期。

  1. 在「收集箱」或某个清单点 ＋，填写标题，按需设置截止日期、优先级、备注和预计用时。
  2. 点「安排到日历」，选择日期、开始和结束时间，再保存。一个任务当前对应一段执行时间；点时间安排旁的 × 可取消排期，任务仍保留。
  3. 点任务卡片可再次编辑。在日历的时间轴中，电脑用鼠标拖动、手机长按后拖动，可调整已有个人安排；课程不支持这样移动。

「今天」页或日历里的 ＋ 用来添加有起止时间的独立日程，适合运动、聚会等安排；想记录有截止日期的待办，请从清单添加任务。

完成后点勾选框。误勾时，展开「已完成」或从左上菜单进入「已完成」，再点一次勾选框即可改回未完成。

导入自己的课表

  1. 打开「我的 → 导入课表 → 如何获得课表」，按学校教程从自己的教务页面导出课表文件。
  2. 回到应用，点「选择课表文件」，或粘贴导出的 JSON 内容；电脑网页版也可拖入文件，再点「导入课表」。
  3. 在日历中核对学期起始日期、周次、单双周和上课时间，再开始安排其他事情。

现有导出适配包括山东大学（威海教务页面）和哈尔滨工业大学（深圳），具体适用范围以教程为准。导入会替换账号现有课表，请保留原导出文件；课表截图、Excel 等不能直接当作课表 JSON 导入。

查看课表导入教程。还没有自己的学校，可在导入页点「还没有你的学校？提交课表样本」，按提示提供必要信息。

让 Alice 帮忙安排

点击 🎀 打开 AI 计划助手。告诉它想做什么、什么时候要完成、预计多久，以及希望避开或留出的时间。还没有建好的任务，也可以直接描述，让它提出新任务和排期。

例如：“帮我安排这周的作业，尽量放在晚饭后，周六下午留给朋友。用时不确定的先帮我估一下。”

  1. 查看方案与「本次要求」。信息不足时补充说明；如果希望先估时，可以明确告诉助手。
  2. 继续对话调整，选择要采用的安排，再点「应用选中的…项」或「应用安排」，确认后才会写入。
  3. 可从历史记录找回之前的方案；已应用的安排可尝试「撤销这次应用」。相关内容已被修改或恢复位置被占用时，撤销会停止，请核对后手动调整。

AI 需要联网，生成、应用和撤销前需先同步本机日历修改。方案仅供参考，请核对日期、用时和冲突；当前不能直接修改课程，也不能把一个任务自动拆成多段排期。

获取并配置自己的 API Key · 通过 MCP 连接自己的智能体

DDL Killer 是完全免费的软件。官方 AI 免费额度用于让新用户体验助手，判断是否适合自己。这些 AI 调用会增加我们的运营成本；助手目前处于测试阶段，免费额度可能随成本和运行情况调整，具体以应用内显示为准。长期使用建议配置自己的 API Key，或通过 MCP 接入自己的智能体。第三方模型或智能体服务的费用按对应服务商规则由你承担，DDL Killer 不收取任何软件使用费用。任何以 DDL Killer 官方名义收取软件使用费用的行为均非官方，请勿付款。

离线、同步与换设备

“已保存到本机”和“已同步”是两件事。本机指你当前使用的浏览器或 Android 应用；只有同步成功的内容，才能在另一台设备登录后看到。

当前设备的修改→同步成功，保存到账号→新设备联网登录后读取

先准备好，再离线使用

登录时勾选「在此设备启用离线数据」，联网进入「我的 → 同步与离线数据」，等待显示「已同步」。网页版如仍提示「网页离线资源准备中」，请继续保持联网。完成准备后，可以离线查看和编辑已下载的清单、任务、日程与课表；AI、邮箱验证等功能仍需联网。

取消离线勾选后为公共设备模式：数据只留在当前页面，关闭页面后未同步修改会丢失。不要把这种模式当作离线备份。

有待同步内容或冲突时

出现「待同步…项」时，修改还在本机。恢复网络并打开应用后会尝试自动同步，也可进入「同步与离线数据」点「立即同步」。登录失效时，按提示重新登录原账号，本机修改会保留。

出现「有修改需要处理」时，比较「本机修改」与「线上当前内容」，选择「保留我的修改并重新同步」或「放弃这次修改，使用线上版本」。如果线上内容已删除，可能需要先导出本机内容，再重新创建。

换设备、退出或清理之前

先在旧设备确认「已同步」，再到新设备联网登录同一账号。正常退出会清除当前设备的本地数据，已同步的在线数据保留；有待同步修改时，应用会阻止直接退出或切换账号。

无法同步时，先点「导出本机数据与待同步修改」，确认文件确实已保存，再决定如何处理。清理浏览器网站数据、更换浏览器或卸载应用，也可能移除这份本地数据；未同步内容不会自动转移到其他设备。

两种导出用途不同：「同步与离线数据」里的导出包含本机内容和待同步修改；「安全与隐私」里的「导出我的数据」只导出服务器已收到的账号资料。导出文件请妥善保管，目前没有一键导入全部数据的恢复入口。

账号与数据

  • 邮箱与密码：在「我的 → 邮箱」绑定或更换邮箱。更换需要当前密码、新旧邮箱验证码；原邮箱无法收信时，请联系开发者核实处理。登录页的「忘记密码？」可通过已绑定并验证的邮箱设置新密码，尚未绑定邮箱的旧账号需联系开发者。验证码 10 分钟内有效；没有收到，请重试或联系开发者。
  • 导出资料：先确认已同步，再到「我的 → 安全与隐私 → 导出我的数据」，联网输入当前密码后保存文件。
  • 删除与还原：左上菜单的「回收站」可还原误删内容。回收站按当前规则保留 7 天，已完成任务保留 3 天后永久清理；「清空」或「永久删除」无法撤销。
  • 退出与注销：「安全与隐私」提供退出所有设备和永久注销账号。注销会删除在线账号资料与任务等数据，不能撤销；历史备份按保留期限清理，请先导出需要的资料。

阅读完整隐私说明

开启任务提醒

  1. 编辑任务，在「提醒」中选择截止时、提前提醒或自定义时间，再保存。只有日期而没有截止时刻的任务，可选截止当天 09:00。
  2. 到「我的 → 任务提醒」，点「开启 / 检查权限」，按系统提示授权，再点「发送测试提醒」检查效果。

每台设备都需要分别开启通知。安卓已同步提醒由系统触发，准时提醒还需要允许系统的「闹钟和提醒」权限，部分手机还需允许后台运行；其他设备修改任务后，请打开本机应用同步，才能更新本机提醒。网页版后台推送需要浏览器、系统允许通知，并能连接推送服务，不能保证断网时送达。

默认隐藏通知中的任务内容，可在提醒设置中调整；不授予通知权限，也能正常使用清单和日历。

常见问题

为什么任务在清单里，却没出现在 DDL 页？

先确认设置的是「截止日期」，而不只是「安排到日历」的执行时间。DDL 页聚焦已过期和未来 30 天内的任务；更远期任务会保留在原清单，临近后再纳入。

手机和电脑的数据不一致怎么办？

确认使用同一账号，并在两端打开「我的 → 同步与离线数据」点「立即同步」。先处理待同步修改、登录失效或冲突；正式版与 Beta 的业务数据独立，不会互相同步。

课表日期或上课时间不对怎么办？

核对导出时选择的学期、第 1 周日期、周次和作息，确认教程适用于自己的校区与教务系统。课程来自导入课表，不能用拖动个人任务的方式改课；修正文件后重新导入，再检查实际日期。

AI 没生成方案，或者提示暂时不能继续？

先检查网络、同步状态及应用显示的额度或等待时间；使用自己的 Key 时，到「AI 计划助手设置」先保存配置，再「测试连接」。不要反复点击发送；按提示重试，并可从历史记录核对是否已有方案。仍有问题请提交反馈，附错误提示即可，不要附 Key 或密码。

误勾、误删或误应用了安排，怎么处理？

误勾任务可在「已完成」里再次点勾；误删内容可在「回收站」点「还原」，到期或永久清理后无法找回。AI 应用可从历史记录尝试「撤销这次应用」；若相关内容已变化，按提示手动调整。

发现问题，或者想建议适配自己的学校？

到「我的 → 问题与建议」说明操作步骤、预期效果和实际结果，可附去掉个人信息的截图；回复在「我的 → 消息」查看。课表需求也可从导入页的学校反馈入口提交，不要发送教务密码、Cookie 或他人的课表。
